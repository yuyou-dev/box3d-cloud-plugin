# Box3D 云端工作台插件

> v0.2.2：已在 macOS Codex 桌面环境完成真实魔搭登录、工作区配对、云端新建/另存/改稿及保存重开 2D/3D 验证。Windows/Linux 安装脚本已提供，尚未完成对应实机验收。

这是 Box3D 的公开 Codex 插件市场和薄 MCP 连接器。盒型算法、折叠几何、渲染、导出和用户工程保存在云端服务；本仓库不包含 Box3D 服务端或管理员凭据。

把下面这句话发给客户的 Codex：

> 帮我安装并连接 Box3D 云端工作台，按 https://raw.githubusercontent.com/yuyou-dev/box3d-cloud-plugin/v0.2.2/START_HERE.md 自动完成配置并打开登录页；魔搭和 Box3D 账号密码由我在浏览器中输入。

客户需要 Codex 桌面环境、自己的魔搭账号及管理员单独提供的 Box3D 邀请账号。首次安装与账号授权遵循客户设备的安全确认。支持的安装脚本覆盖 macOS、Linux 和 Windows；实际完成验证的系统见发行说明。

这是自有 GitHub 插件市场分发，不代表已进入 OpenAI 审核的公共插件目录。无需取得私人源代码或手工拼 MCP 配置。

## 从设计师视角验收

1. 发送上面的启动句，看见“正在安装”和浏览器登录页。
2. 登录魔搭，再登录自己的 Box3D 工作区，用页面中的配对码确认连接。Codex 回复“已连接你的工作区”。
3. 说：“做一个 220×50×215 mm 的反向插口彩盒，黑底，正面 ORBIT 01，金银轨道，烫金、烫银、击凸分别可编辑。先给我看展开图和成盒效果。”
4. 说：“另存一份，正面改成 ORBIT 02，其余不变，保存后重新打开。”确认两份工程都在，尺寸一致。
5. 关闭这次聊天，再打开新聊天说“打开我刚做的 ORBIT 02”，确认登录仍有效，项目能重新打开。
6. 说：“导出印刷 PDF、三种工艺分版和 1:1 刀版，下载给我；没有 ICC 的保留草案标记。”确认收到可打开的实际文件。

没有弹出登录页、显示了别人的工作区、只有首页却声称工程已打开，或没有文件却声称下载完成，均为未通过。
