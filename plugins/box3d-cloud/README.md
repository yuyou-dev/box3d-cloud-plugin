# Box3D Cloud 0.2.0

面向受邀设计师的薄连接器。使用发布仓库的 START_HERE.md 安装，不需要开发源码环境。

MCP 与 CLI 使用同一连接流程：官方魔搭 OAuth（授权码、state、nonce、PKCE）→ Box3D 浏览器会话确认配对码 → 本机保存独立的 30 天工作区凭据 → 远程 MCP。魔搭访问令牌仅发往官方 OAuth 端点及固定创空间 API origin；不会带入工作区子进程或发给其他地址。管理员平台密钥不随插件分发。

本机数据目录默认 `~/.box3d-cloud`；POSIX 目录 0700、连接文件 0600，Windows 设置仅当前用户访问。连接文件包含敏感凭据，不应发到聊天、工单或截图。工程交付下载默认 `~/Downloads/Box3D`，按摘要核验，不覆盖不同内容文件。

已发布 dist 文件包括第三方依赖和许可说明。`scripts/` 仅包含连接、认证、上传下载与安装所需代码，不含几何、排版或导出算法。开发者可用 `npm ci && npm run build` 复现；客户安装不执行构建。
